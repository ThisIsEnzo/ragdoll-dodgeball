# MOBILE / PERF / SECURITY — что закрыто в S6

## Мобильный ввод

| Было | Стало |
|---|---|
| `MouseButton1Up` на кнопке: палец съехал — заряд залип навсегда | глобальный `InputEnded` отпускает заряд где угодно |
| кнопки 62 px высотой | 88 px.compact, THROW 96 px |
| hype-полоса на джойстике | на компакте уезжает наверх под счёт |
| панель квестов перекрывала левый нижний угол | свёрнута в кнопку с счётчиком доступных наград |
| прицел только камерой, aim assist отсутствовал | серверный assist: 5° desktop, 11° mobile |
| рывок по направлению камеры | рывок по `Humanoid.MoveDirection`, то есть по джойстику |
| геймпада не было | R2 бросок, X ловля, B рывок, Y ульта |
| notch мог съесть кнопки | `ScreenInsets = DeviceSafeInsets` |

Страховка заряда: если он держится дольше 3 секунд, выстрел происходит сам.
Потеря фокуса окна заряд отменяет, а не выстреливает.

### Aim assist спроектирован как серверная функция

Клиент присылает только направление камеры. Сервер сам ищет ближайшую живую цель
внутри разрешённого конуса, проверяет линию видимости рейкастом, подмешивает
направление с силой 0.55 и **жёстко клампит суммарное отклонение** разрешённым углом.

Читер не может получить больше помощи, чем обычный мобильный игрок: он не управляет
ни выбором цели, ни углом. Флаг `IsMobile` приходит с клиента и теоретически подделываем,
но выигрыш ограничен 6 градусами — это не аимбот.

## Перф-бюджет

| Источник расхода | Было | Стало |
|---|---|---|
| ragdoll в покое | write velocity каждый кадр, до 480/с при 8 телах | один финальный write, дальше тело не трогаем |
| ProfileState | пакет на каждый бросок, до 4/с на игрока | dirty-флаг, флаш 5 Гц |
| QuestState | пакет на каждый бросок | тот же флаш |
| `SessionSeconds` | атрибут всем игрокам каждую секунду | серверная таблица, ноль репликации |
| тени арены | включены на всех деталях | выключены через perf-setup |
| стриминг | выключен | min 64, target 256, MinimumRadiusPause |

Бюджет: 60 FPS на mid-tier Android, 30 минимум, не больше 3000 деталей на арене,
не больше 8 активных ragdoll, все детали арены Anchored.

Проверка: `tools/perf-setup.lua` в Edit, затем `tools/perf-report.lua` в Play.
Отчёт печатает вердикт по каждому пункту, FPS измеряется в клиентском контексте.

## Аудит анти-чита

| Вектор | Проверка | Последствие |
|---|---|---|
| Спам одного remote | per-action лимит из `RateLimits` | drop + страйк |
| Флуд разными remote | общий бюджет 30 вызовов/с | drop + двойной страйк |
| Speed hack | watchdog 5 Гц, горизонтальная скорость против `WalkSpeed*1.5+10` | 3 подряд нарушения → rubber-band + 3 страйка |
| Подмена WalkSpeed | сверка каждые 2 с, порог 1.35× | сброс значения + 3 страйка |
| Подмена JumpPower | порог 1.5× | сброс + 2 страйка |
| Телепорт-чит | одиночный скачок > 60 studs трактуется как серверный телепорт | не наказывается |
| Подделка заряда | диапазон 0.15–0.9 с | drop |
| Подделка направления | тип, конечность, нормализация | drop |
| Точка броска далеко от тела | leeway 8 studs | используется серверная позиция |
| Ping вне арены | границы арены + 120 studs от игрока | drop |
| Ложная ловля | вся геометрия на сервере + lag-comp | не проходит |
| Ложный квест | прогресс только серверный | не проходит |

Страйки затухают на 1 каждые 5 секунд, чтобы лаг не приводил к кiku честного игрока.
Кик только при 15 накопленных страйках. Каждое срабатывание уходит в аналитику
событием `security_flag` с причиной и суммой — по нему видно, не ловим ли мы нормальных игроков.

### Осознанно не закрыто

- Клиент владеет своим Humanoid, поэтому микро-телепорты в пределах допуска возможны.
  Полностью это лечится только серверной симуляцией движения, что убьёт отзывчивость.
- `IsMobile` подделываем. Влияние ограничено конусом aim assist.
- Визуальные эффекты клиент может вызвать только через серверные события, но
  `ping` остаётся единственным местом, где клиент передаёт произвольную позицию —
  она клампится ареной и дистанцией.

## Что проверить руками

1. Device Emulator 360×640: зажми THROW, съедь пальцем за кнопку, отпусти.
   Бросок должен пройти, полоса заряда обнулиться.
2. Device Emulator 800×360 (ландшафт): кнопки не перекрывают друг друга и джойстик.
3. Геймпад: R2 заряжает и бросает, X ловит.
4. `perf-report` в Play: arena parts ≤ 3000, unanchored 0, shadows 0, FPS ≥ 60 на PC.
5. Тест чита: в клиентском контексте поставь `Humanoid.WalkSpeed = 120`.
   В течение 2 секунд значение должно вернуться, в Output появиться `[Security] walkspeed tamper`.
6. Тест ложного срабатывания: сыграй нормальный матч с рывками и ragdoll.
   Страйков быть не должно. Если есть — поднимай `SpeedTolerance` и `SpeedSlack`.

Пункт 6 важнее пункта 5. Ложный кик честного игрока стоит дороже, чем пропущенный читер:
он приходит один раз и больше не возвращается, а D1 у нас главный KPI.
