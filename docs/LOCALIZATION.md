# LOCALIZATION — английский как основной язык

## Решение

Все игроцкие строки живут в `src/shared/Strings.lua`. В коде их больше нет.
`BalanceConfig.Locale.Force = "en"` держит английский принудительно — это нужно для
американского рынка и для того, чтобы клипы и скриншоты были на одном языке.

Когда придёт время включать автоопределение: поставь `Force = nil`.
Тогда клиент возьмёт `Player.LocaleId`, отбросит регион (`en-us` -> `en`) и подставит локаль,
если она заполнена. Незаполненная локаль или отсутствующий ключ всегда падают назад на английский.

## Что уже переведено

HUD: ожидание, состояния раунда, VICTORY / DEFEAT, REMATCH, уровень, монеты, стрик,
дейли-квесты, CLAIM / DONE, LEVEL UP, UNLOCKED, PROGRESS NOT SAVED, кнопки THROW / CATCH / DODGE / ULT.

Косметика удара уже была английской: BONK, WHAM, POW, OOF, BOOP, CAUGHT, BACK IN, BLOCKED.
Баннеры моментов: DOUBLE BONK, CLUTCH CATCH, SUDDEN DEATH WIN.

Комментарии в коде и логи разработчика намеренно не переводятся: игрок их не видит.

## Тон голоса

Аудитория 9–16, американский рынок. Правила:
- Коротко, капсом, без вежливости и без объяснений. `GET READY`, не `Please wait for the match`.
- Никакого сленга, который устареет за месяц. Brainrot-лексика запрещена: тренд уже схлопнулся.
- Никаких упоминаний боли и травм. `BONK`, `OOF` — мультяшно. `KILLED`, `DESTROYED` — нет.
- Числа всегда цифрами. `LVL 12`, не `Level twelve`.
- Квесты — глагол в начале: `Knock out 12 opponents`, не `You need to knock out...`.

## Как добавить язык

1. В `Strings.lua` заполни таблицу `es` или `pt` теми же ключами.
2. Ничего в коде менять не нужно: фолбэк на EN сработает для незаполненных ключей.
3. Проверь длину строк: испанский и португальский длиннее английского на 20–30%.
   Панель квестов шириной 232 px обрезает текст по концу — длинные формулировки сокращай.
4. Прогони игру с `Force = "es"` и посмотри HUD на телефоне.

Приоритет языков по данным исследования: EN основной, затем ES и PT-BR.
Больше 70% аудитории Roblox вне RU, поэтому русский в игре не нужен вообще —
он оставлен в таблице пустым слотом только как заготовка.

## Нативный путь Roblox (на будущее)

Когда строк станет больше сотни, имеет смысл переехать на `LocalizationTable` в
ReplicatedStorage и `LocalizationService:GetTranslatorForPlayerAsync`. Это даст
автоперевод через Creator Hub и плюрализацию. Текущая таблица спроектирована так,
что миграция механическая: ключи уже плоские и стабильные.

## Проверка

В Output при старте сервера:

    [Progress] PlayerName day 20000 streak, +100 coins, daily quests rolled
    [RagdollDodgeball] v0.5.0 server up: English UI, persistence, XP, coins, daily quests

Если видишь `PROGRESS NOT SAVED` в HUD — DataStore недоступен.
Включи Game Settings → Security → Enable Studio Access to API Services.
Игра при этом работает, просто прогресс живёт только в текущей сессии.
