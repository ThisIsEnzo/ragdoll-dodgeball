# GAME DESIGN DOCUMENT — RAGDOLL DODGEBALL v1.0

Питч: командные вышибалы, где каждое попадание отправляет соперника в смешной ragdoll-полёт,
а поймавший мяч возвращает в игру выбитого товарища.

## A1. Рамки продукта

| Параметр | Значение |
|---|---|
| Жанр | Sports & Racing / командный физика-спорт |
| Аудитория | 9-16 ядро, 17-24 вторичка, 70%+ mobile |
| Приоритет устройств | Android mid-tier, iOS, PC, консоль |
| Сессия | 12-20 мин (2-4 матча) |
| Матч | 4-6 мин (best of 5, раунд 75 с) |
| Языки | EN основной + ES / PT-BR / RU |
| Рейтинг | All Ages / 9+, без крови |
| KPI | D1 >= 25%, сессия >= 15 мин, co-play >= 35% |

Три столпа:
1. Читаемость за 3 секунды: попал мячом = соперник улетел. Без HP-полосок.
2. Клатч всегда возможен: ловля переворачивает раунд.
3. Скилл решает, кошелёк украшает: весь платный контент косметический.

## A2. Core loop

    МОМЕНТ (2-8 с):  увидел мяч -> увернулся/поймал -> бросил -> BONK
    РАУНД (75 с):    выбить всех или дожить с большинством
    МАТЧ (5 мин):    3 победы -> монеты + XP + квесты
    СЕССИЯ (15 мин): 2-4 матча -> уровень -> разблокировка -> ещё один
    ДЕНЬ:            3 дейли + стрик + rewarded video (лимит 5)
    НЕДЕЛЯ:          пятничный апдейт, ранкед-сезон 14 дней, ротация шопа

## A3. Режимы и правила

| Режим | Состав | Раунд | Матч | Приоритет |
|---|---|---|---|---|
| Casual | 3v3 | 75 с | до 3 побед | вход по умолчанию |
| Duel | 2v2 | 60 с | до 3 побед | пати-режим |
| Ranked | 4v4 | 75 с | до 3 побед | с 10 уровня |
| Chaos FFA | 8 | 90 с | 1 раунд | ивент выходного дня |

Правила раунда:
- Мячей: 3 (3v3) / 4 (4v4), спавн на центральной линии.
- Попадание = выбит: ragdoll 2.5 с, затем скамейка до конца раунда.
- Ловля = бросавший выбит + один твой выбитый воскрешает (ближайший к скамейке).
- Мяч, коснувшийся земли или стены, ловить нельзя.
- Таймер истёк: побеждает команда с большим числом живых.
- Равенство: Sudden Death 20 с, арена сжимается на 25%, скорость мячей +20%.
- Анти-кемпинг: мяч в руках > 6 с подсвечивается, на 8 с выпадает.

Скамейка: выбитый не скучает — кидает эмоции и пингует опасность (1 пинг / 5 с).
Максимальный простой ограничен длиной раунда (75 с).

## A6. Прогрессия

Уровни 1-100. XP: победа 120, поражение 70, +8 попадание, +20 ловля, +15 воскрешение.
Кривая: XP_to_next = 200 + 60 * level^1.35. Уровень 2 обязателен на 2-й минуте FTUE.

Ранкед: сезоны 14 дней, Wood / Bronze / Silver / Gold / Diamond / Pro / Legend по 3 дивизиона.
MMR Elo K=32, 5 калибровочных, софт-ресет -1 дивизион. Топ-100 leaderboard.

Квесты: 3 дейли по 150 монет, 2 викли по 500 + 250 XP.
Реролл: 1 бесплатный в день, дальше 100 монет или rewarded video.

| Время | Событие |

## A10. Виральность

- Авто-детект моментов: multi_ko (2+ одним мячом), clutch_catch (ловля при 1 живом), sudden_death_win.
  Клиент показывает кнопку Сохранить момент.
- Геймплей-видео для Home: 12-18 с, реальный матч, без озвучки и монтажных трюков.
- Заявка в Standout Games после появления механики ловли-воскрешения.
- TikTok / Shorts: 3-5 роликов в неделю.
- Промокоды в описаниях: 500 монет, 1 на аккаунт.

## A11. Аналитика

События: ftue_step, first_throw, first_catch, match_start, match_end, round_end, ko, catch,
revive, ult_used, quest_claim, level_up, shop_view, purchase, rv_shown, party_join, rage_quit.

Воронка: спавн -> первый бросок -> первый матч доигран -> второй матч -> D1.
