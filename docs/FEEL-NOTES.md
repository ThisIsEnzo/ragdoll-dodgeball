# FEEL NOTES — модель отката и тест Phase 0

Это документ про ощущения. Именно они решают, будет ли игра виральной, а не количество фич.

## Что было сломано в v0.2.1

| Симптом | Причина | Цифра |
|---|---|---|
| Игрок улетает за арену | импульс = скорость мяча x 1.4, прибавлялся к текущей скорости | до 182 studs/s при WalkSpeed 18 |
| Игрок улетает даже без нашего импульса | мяч Density 1.0 при диаметре 2.2 | масса мяча 5.6, примерно треть массы персонажа |
| Батут при беге с мячом | неanchored мяч телепортировался в руку и пересекал капсулу | смещение 1.4 при радиусе 1.1 |
| Попадания иногда не считаются | Touched при 130 studs/s: 2.2 studs за кадр = диаметр мяча | туннелинг |

## Что стало

Перенос мяча: `Anchored = true`, `CanCollide = false`, `CanTouch = false`, группа `HeldBalls`
не сталкивается ни с чем. Anchored-деталь не может толкнуть персонажа физически.

Попадания: `workspace:Spherecast` от предыдущей позиции мяча к текущей, радиус = половина мяча.
Туннелинг невозможен. Мяч не сталкивается с игроками вообще — откат полностью скриптовый.

Откат:
    power   = clamp(ballSpeed * SpeedToImpulse, MinLaunch, MaxLaunch)
    flat    = min(horizontal, MaxLaunch)
    vertical= clamp(impulse.Y * VerticalScale, -MaxVertical, MaxVertical)
    root.AssemblyLinearVelocity = Vector3.new(flat.X, vertical, flat.Z)   -- замена, не сумма
    каждый кадр: horizontal *= DragPerFrame ^ (dt * 60)

Ожидаемая дистанция кувырка: примерно `MaxLaunch * 0.0167 * k / (1 - k)`,
при MaxLaunch 42 и DragPerFrame 0.90 это около 6 studs. При типичном попадании
на скорости 100 мощность 28 → около 4 studs.

## Ручки настройки

| Хочу | Меняю |
|---|---|
| Смешнее, дальше летит | MaxLaunch 42 → 55, Spin 8 → 14 |
| Строже, почти без отката | MaxLaunch 42 → 30, DragPerFrame 0.90 → 0.85 |
| Больше кувырка, меньше скольжения | Spin 14, DragPerFrame 0.82 |
| Чтобы не подпрыгивал вообще | VerticalScale 0.35 → 0.1, MaxVertical 12 → 4 |
| Чтобы ловля была щедрее | CatchGrace 0.15 → 0.22, Catch.Window 0.35 → 0.45 |
| Чтобы мяч было легче подобрать | Ball.PickupMaxSpeed 35 → 50 |

Менять только в BalanceConfig. В коде чисел нет.

## Тест Phase 0 (go / no-go)

Прогони на 5 живых людях, не на себе. Ты знаешь управление и не считаешься.

1. Дай поиграть 60 секунд без объяснений. Считай, через сколько секунд первый бросок.
   Цель: до 10 секунд.
2. Спроси после первого попадания по боту: смешно или раздражает?
   Цель: 8 из 10 смеются или просят ещё.
3. Спроси: понял, что ловля воскрешает союзника? Если нет — механика не читается, нужен VFX и подсказка.
4. Проверь на телефоне: попадает ли большой палец в THROW, не перекрывает ли HUD арену.
5. Запиши 3 клипа по 10 секунд. Если ни один не хочется переслать другу — импакт ещё не готов.

Пока этот тест не пройден, новые фичи не пишем. По ROADMAP это гейт Phase 0,
и он важнее ранкеда, пасса и магазина вместе взятых.
